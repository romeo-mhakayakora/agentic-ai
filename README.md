# ai-agents-mastery

Course-style repository scaffold for learning and practicing agentic AI.

## Structure

- `docs/`: architecture and setup notes
- `module-00-intro/` .. `module-07-post-deployment/`: modules with lectures and (where applicable) labs

## Quick start

1. Create a virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Open labs in Jupyter.
